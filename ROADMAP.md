# Roadmap

## Milestone 1 — текстовый преподаватель

Код реализован; реальная проверка внешних интеграций и официальных источников остаётся отдельным условием приёмки.
- [x] Архитектура модульного монолита и границы Learning Core.
- [x] Нативные роли Codex, проверка доступности моделей и практического делегирования.
- [x] Независимая проверка базовой педагогической логики.
- [x] Регистрация и редактирование профиля, долговечное состояние Telegram.
- [x] Текстовая диагностика четырёх навыков, осторожная интерпретация результата.
- [x] Индивидуальный план, занятия, адаптивная практика и ошибки.
- [x] Внутреннее расписание, дедлайны и история переносов.
- [x] OpenRouter: схемы, ограниченный контекст, повтор запросов, учёт использования.
- [x] PostgreSQL, миграции, изоляция, дедупликация и восстановление.
- [x] Compose, инструкции запуска и функциональная проверка.
- [x] Независимое ревью и исправление значимых замечаний.
- [ ] Проверка Telegram и OpenRouter с реальными ключами (ключи пока отсутствуют).
- [ ] Независимое подтверждение актуальных материалов ILR (сеть блокирует официальные сайты).

## Следующие этапы — не реализовывать сейчас
- Google Calendar через уже предусмотренный порт: синхронизация событий и переносов.
- STT, TTS, аудиоанализ и отдельная диагностика говорения/аудирования.
- Anki import/export после отдельного определения контракта и правил повторения.
- Подготовка к собеседованию по гражданству как отдельная программа при необходимости.

Оценки модели — учебная обратная связь. Ни один этап не вводит вымышленные официальные проходные баллы.
