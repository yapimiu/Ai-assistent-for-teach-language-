# ROMÂNĂ B1 — персональный текстовый преподаватель

Telegram-бот для подготовки к румынскому B1, с ILR в качестве экзаменационной организации по умолчанию. Объяснения — преимущественно на русском, практика — на румынском. Диагностика и оценки модели имеют учебный характер: они не являются официальным результатом экзамена. Аудирование и говорение в Milestone 1 остаются непроверенными.

## Команды
| Команда | Назначение |
|---|---|
| `/start` | Регистрация и профиль |
| `/test` | Чтение, грамматика, лексика и короткое письмо |
| `/plan` | Индивидуальная программа |
| `/today` | Задания, ближайшие сроки и переносы |
| `/lesson` | Начать или продолжить занятие |
| `/practice` | Дополнительная практика слабых тем |
| `/mistakes` | История ошибок и исправлений |
| `/progress` | Учебные результаты и непроверенные навыки |
| `/settings` | Редактирование профиля и режима |

Незавершённое занятие и ответы сохраняются в PostgreSQL. Повторное получение одного сообщения не должно повторно начислять прогресс. Teaching Mode даёт объяснения и постепенно уменьшает подсказки; Exam Mode откладывает разбор до завершения задания.

## Данные и границы
Ответы и исправления сохраняются в вашей базе. Для проверки задания необходимый фрагмент ответа и учебного контекста отправляется выбранной модели через OpenRouter. Полная переписка в каждый запрос не передаётся. Держите базу в закрытой сети, не публикуйте токены и не коммитьте `.env`.

Google Calendar, голосовые функции и Anki оставлены на следующие этапы. Подготовка к собеседованию по гражданству не смешивается с языковым экзаменом.

## Запуск через Docker Compose

Нужны Docker с Compose, токен бота из BotFather и ключ OpenRouter. В каталоге проекта:

```bash
cp .env.example .env
# Заполните TELEGRAM_BOT_TOKEN и OPENROUTER_API_KEY в .env.
# Задайте POSTGRES_PASSWORD; пример romana предназначен только для локальной разработки.
docker compose up --build -d
```

Compose поднимает PostgreSQL, применяет миграции, затем запускает API и бота. Данные сохраняются в томе `postgres_data`; `docker compose down` сохраняет его. Не используйте `down -v`, если хотите сохранить историю обучения. API привязан к loopback хоста: `/health` проверяет процесс, `/ready` — доступ к базе и таблицам. Это служебный API без доступа к персональным данным.

```bash
docker compose logs --tail=100 bot api migrate
docker compose down
```

## Конфигурация

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Секрет Telegram; нужен только процессу бота |
| `OPENROUTER_API_KEY` | Секрет OpenRouter для генерации и проверки |
| `DATABASE_URL` | SQLAlchemy URL PostgreSQL; Compose задаёт адрес `db` автоматически |
| `POSTGRES_PASSWORD` | Пароль PostgreSQL в Compose; используйте URL-safe значение |
| `MODEL_TUTOR` | Модель генерации задания |
| `MODEL_ASSESSOR` | Модель проверки ответа |
| `MODEL_MAX_TOKENS` | Лимит выходных токенов одного запроса |
| `MODEL_TIMEOUT_SECONDS` | Тайм-аут HTTP-запроса |
| `MODEL_RETRIES` | Число повторов при временных сетевых ошибках |
| `OPENROUTER_BASE_URL` | По умолчанию `https://openrouter.ai/api/v1` |
| `TEST_DATABASE_URL` | Отдельная одноразовая база для интеграционных тестов |

Выбранная модель должна поддерживать JSON-ответы. Модель и доступность тарифа выбираются владельцем ключа; результат проверяется Pydantic. Стоимость сохраняется по данным провайдера; отсутствующая стоимость остаётся неизвестной.

## Локальная разработка

Python 3.12+, uv и PostgreSQL 17:

```bash
uv sync --frozen
# Настройте .env с DATABASE_URL для своей локальной базы.
uv run alembic upgrade head
uv run uvicorn app.api:app --host 127.0.0.1 --port 8000
# В другом терминале:
uv run python -m app.bot
```

## Первый учебный цикл

1. Отправьте `/start` и ответьте на вопросы. `-` выбирает указанное значение по умолчанию.
2. Выполните четыре задания `/test`. Это предварительная текстовая диагностика.
3. Откройте `/plan`, затем `/lesson` и ответьте на румынском.
4. Изучите разбор, выполните повторное самостоятельное задание, проверьте `/mistakes` и `/progress`.
5. `/today` запускает пересчёт пропущенных задач и показывает ближайшие сроки. Переносы записываются; конечная дата сохраняется, нехватка времени обозначается предупреждением.
6. `/practice` предлагает работу со слабыми темами. `/lesson` продолжает сохранённое занятие после перезапуска.

Настройки редактируются, например: `/settings weekly_hours=4`, `/settings timezone=Europe/Moscow`, `/settings mode=exam`. Во время активного занятия режим фиксирован. `/finish` завершает занятие; `/replan` пересчитывает план после изменения профиля. Экзаменационный режим — учебная симуляция, а не официальный экзамен ILR.

## Проверки

```bash
uv run pytest -q
# Полная проверка требует ОТДЕЛЬНОЙ одноразовой PostgreSQL-базы:
TEST_DATABASE_URL=postgresql+psycopg://user:password@localhost:5432/romana_test uv run pytest -q
```

Интеграционные тесты могут очищать таблицы тестовой базы. Никогда не направляйте `TEST_DATABASE_URL` на базу с реальными данными. Без этой переменной PostgreSQL-тесты пропускаются, что не подтверждает работу хранения. Результаты выполненных проверок и оставшиеся ограничения фиксируются в `docs/VALIDATION.md`.

## Облачная среда с HTTPS-прокси

Если Docker не доверяет сертификату прокси, передайте доверенный системный CA как временный секрет BuildKit: `docker build --secret id=build_ca,src=/etc/ssl/certs/ca-certificates.crt -t romana-b1:milestone1 .`. При необходимости добавьте `--build-arg HTTPS_PROXY --build-arg HTTP_PROXY --build-arg NO_PROXY` и `--add-host` для имени прокси, разрешённого в текущей среде. CA не копируется в итоговый образ. Проверка TLS и хешей пакетов остаётся включённой.

В этой облачной среде черновик конфигурации содержит требования к двум ключам и сетевым доменам. Значения вводятся в настройках среды, не в чате. Настройки необходимо сохранить и опубликовать через интерфейс среды; сохранённый агентом черновик сам по себе не применяет их к запущенным процессам.
